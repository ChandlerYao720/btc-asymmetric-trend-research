## 系统结构

| 层级 | 研究职能 | 严格边界 |
| --- | --- | --- |
| **01 · 趋势方向** | 在已收盘四小时 K 线上进行多周期唐奇安通道投票 | 只决定做多、空仓或做空 |
| **02 · 市场环境** | 五状态因果引擎综合趋势、波动率、通道位置、动量和衍生品环境 | 只约束风险，不产生方向 |
| **03 · 风险预算** | 根据市场环境与已实现波动率确定目标仓位 | 仓位始终位于 −100% 至 +100% |
| **04 · 机器学习否决** | 采用滚动扩展训练窗口和时间前推测试的可解释决策树 | 只能把做空变为空仓，不能开仓、反向或扩大仓位 |
| **05 · 利润保护** | 因果最大有利波动状态机监控浮盈回吐 | 只能减仓或退出，不能恢复、反向或加仓 |
| **06 · 执行研究** | 历史一秒级 L1 最优买卖价在部分事件上替换成交价 | 只改变成交价格，不改变方向或仓位 |
| **07 · 成本账本** | 显式记录手续费、换手和成交价格 | 生成含成本权益路径 |

展示架构用于说明能力和决策边界，并不提供可直接复刻策略的全部细节。具体因子定义、阈值、拟合后的树规则、数据连接方式和生产执行逻辑均保留在私有研究环境中。

## 机器学习与市场环境

机器学习模块只承担一个范围很窄的任务：识别对空头不利的市场上下文，并通过 **做空 → 空仓** 否决风险。输入覆盖趋势延续、价格路径质量、通道位置、已实现波动率、衍生品拥挤程度和父级仓位环境等因果特征族。未来收益只用于构造训练标签；实际推断仅使用决策时点已经可见的信息。

五状态市场环境引擎与分类器相互独立。它将趋势强度、价格位置、方向动量、已实现波动率、资金费率与溢价环境、持仓量与挤压风险映射成因果状态，再交给风险预算层决定仓位。衍生品数据只描述市场状态和拥挤风险，不负责产生交易方向。

## 高频研究的展示边界

主回测是一套**四小时策略**，不宣称已经形成可实盘复现的高频交易系统。页面展示的执行模块属于历史**一秒级 L1 研究**：

- 已执行调仓的一档行情覆盖率为 94.11%
- 63 个事件采用历史执行价替换
- 61 笔交易受到影响
- 入选事件的平均成交价改善为 +0.0188%

私有研究库还覆盖一秒收益与波动率、L1 买卖价差、微价格、队列不平衡、有符号成交流、VWAP（Volume-Weighted Average Price，成交量加权平均价；用于衡量成交价格相对短期交易重心的偏离）、事件时间订单流不平衡、多档盘口深度、订单簿斜率、更新强度与盘口陈旧度。这里将其披露为研究能力，不把整个因子库归因为主策略收益，也不声称与实盘高频执行完全等价。
