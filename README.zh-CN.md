# BTC 非对称趋势策略

这是一套计入交易成本的 BTC/USDT 方向策略，以严格受限的多空仓位表达观点。系统将趋势方向、风险分配、空头过滤、利润保护和成交执行拆分为五个职责清晰的层级，使每一项决策都可单独检查。

## ▶ [点击进入交互式策略回放](https://chandleryao720.github.io/btc-asymmetric-trend-research/)

可在四小时 K 线历史中拖动和缩放，查看同步的目标仓位，并独立显示仓位周期、买卖调仓、市场状态、利润保护与秒级执行事件。

[![BTC 非对称趋势策略交互回放](assets/preview.png?v=20260826f)](https://chandleryao720.github.io/btc-asymmetric-trend-research/)

## 策略结构

| 层级 | 决策 | 严格边界 |
| --- | --- | --- |
| **01 · 趋势方向** | 对已收盘四小时 K 线进行 20、55、100 周期唐奇安通道投票 | 只决定多空方向 |
| **02 · 风险预算** | 依据市场状态与已实现波动率确定目标仓位 | 仓位始终限制在 −100% 至 +100% |
| **03 · 空头风险否决** | 采用浅层滚动前推决策树过滤容易遭遇反弹的空头 | 只能平掉已有空头，不能开仓或扩大仓位 |
| **04 · 利润保护** | 以仅使用当时可见信息的最大有利波动状态机监测浮盈回吐 | 只能减仓或退出，不能恢复、反向或加仓 |
| **05 · 成交执行** | 在证据可用时，以实际观察到的一秒级最优买卖价替换部分成交价 | 只改变成交价格，不改变方向或仓位 |

## 看板可检查内容

- **决策时序：** 在 5,806 根四小时 K 线上拖动和缩放，下方目标仓位与主图保持同步。
- **事件图层：** 独立显示或隐藏多空仓位周期、买卖调仓、市场状态变化、利润保护动作与秒级成交。
- **绩效路径：** 将含成本策略路径与同时钟 BTC 一倍持有进行比较，并查看同一时点的回撤。
- **受控诊断：** 查看共同窗口下的策略变体、市场状态与多空非对称性，以及标准化后的多空交易周期结果。

受控诊断统一使用 5,438 根 K 线的共同窗口。各变体差异存在重叠，应分别解读，不应直接相加。
