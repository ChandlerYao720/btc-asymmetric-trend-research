# 技术模型说明

## 公开研究结论

本作品展示了一套系统化 BTC 量化研究流程：方向信号、风险分配、机器学习约束、持仓生命周期管理、执行研究和成本核算相互分离。公开绩效属于**一倍杠杆历史模拟**，不是实盘业绩，也不宣称已经形成生产级高频交易系统。

公开内容包括系统结构、时序决策、受控比较和证据边界；具体因子公式、阈值、拟合后的树规则、数据连接方式和生产执行逻辑不对外披露。

## 机器学习策略

分类器不是方向信号源。它只负责**坏空头识别**：判断拟议空头是否与历史上容易遭受反弹的环境相似，再通过 **做空 → 空仓** 否决风险。

模型采用可解释决策树，并通过滚动扩展训练窗口和时间前推测试进行验证。较早年份组成训练集，下一年份用于测试。输入特征族包括：

- 多周期收益与趋势延续；
- 价格路径效率与趋势强度；
- 通道位置与方向动量；
- 已实现波动率；
- 资金费率、持仓量、溢价和挤压风险环境；
- 父级目标仓位环境。

未来价格结果只用于构造训练标签；实际推断只使用决策时点可见的数据。标签阈值、概率阈值、拟合后的树结构和特征参数属于私有细节。

在共同窗口受控回放中，移除坏空头否决后的累计收益为 **+304.18%**；包含该否决及其他父级有效结构的参考结果为 **+349.14%**。两者属于系统级重放对比，不应解释成可与其他模块直接相加的独立贡献。

## 五状态市场环境引擎

市场环境层将当时可见的信息映射为五种因果状态。输入覆盖趋势强度、通道位置、方向动量、已实现波动率、资金费率与溢价环境，以及持仓量或挤压风险。

它只负责约束风险预算并压制脆弱空头，不负责判断方向。在共同窗口内，关闭市场状态后累计收益由 **+349.14%** 降至 **+222.41%**；关闭多空非对称结构后降至 **+254.82%**。这些差异相互重叠，需要分别理解。

## 因果持仓生命周期控制

最大有利波动（Maximum Favorable Excursion，MFE）是指一笔持仓截至当前时点曾经达到的最大未实现盈利。状态机把当前浮盈与当时已经观察到的浮盈路径进行比较；当利润回吐达到规则条件时，只能减仓或退出。

该保护器采用递归、仅收缩的路径逻辑：每次动作都会影响之后的仓位状态，且不能恢复已减仓部分、反向或扩大仓位。在共同窗口的覆盖层重放中，父级路径为 **+349.14%**，加入 MFE 保护后为 **+365.79%**。

## 一秒级市场微观结构研究

主策略按四小时 K 线作出决策。一秒级模块属于**历史 L1 执行研究**，不代表实盘高频交易能力已经完成生产验证。

对于少量入选历史事件，研究使用实际观察到的最优买价或卖价替换模型成交价。它只能改变成交价格，不能改变信号方向或目标仓位。

| 执行证据 | 结果 |
| --- | ---: |
| L1 行情覆盖率 | 94.11% |
| 入选历史事件 | 63 |
| 受影响交易 | 61 |
| 入选事件平均成交价改善 | +0.0188% |

更广泛的研究库覆盖一秒收益与波动率、L1 买卖价差、微价格、队列不平衡、有符号成交流、VWAP（Volume-Weighted Average Price，成交量加权平均价；用于衡量成交价格相对短期交易重心的偏离）、事件时间订单流不平衡、多档盘口深度不平衡、订单簿斜率、更新强度和盘口陈旧度。这些内容只表示研究覆盖范围，不归因为主策略收益。

## 证据边界

- 历史绩效不能证明未来收益。
- 公开内容不声称已经实现实盘执行等价性、容量验证、队列优先级建模、市场冲击建模或生产级高频交易准备。
- 受控策略变体共享市场区间和部分决策，其收益差异不是可以相加的因果贡献。
- 公开快照没有逐根 K 线的机器学习否决标签，因此主图不伪造该类事件标记。
- 专有参数和数据工程契约被主动排除，公开说明用于解释能力和边界，而非提供完整复刻方案。

仅为历史模拟，不构成投资建议。
